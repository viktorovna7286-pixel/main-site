# Выгрузка Atlas Group

Актуальные файлы «Атласа» находятся в `Прототип/` этого репозитория.
После push в main изменений этой папки запускается Deploy Atlas to Prototype.
Используются существующие GitHub Secrets FTP_SERVER, FTP_USERNAME, FTP_PASSWORD.
Путь выгрузки зафиксирован: /www/vershina8848.ru/Прототип/.

Deploy to FTP продолжает обновлять «Вершину» и каталог, исключая Прототип/.
Изменения только в Прототип/ не запускают выгрузку основного сайта.
Оба задания используют общую очередь, чтобы не подключаться одновременно.
Полная очистка папки прототипа отключена. Файлы, ранее загруженные вручную,
не удаляются автоматически. Отслеживаемые новым заданием файлы синхронизируются.

Редактировать «Атлас» для публикации нужно здесь, в Прототип/.
Папка brand-palette-site/dist больше не является источником автоматической выгрузки.
Отправка формы ещё не подключена. Абсолютные SEO-адреса пока относятся
к прежнему адресу просмотра; перед публичным запуском нужен окончательный домен.
