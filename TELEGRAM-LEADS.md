# Заявки и Telegram

1. Откройте `https://vershina8848.ru/leads-admin.php` и войдите паролем админки каталога.
2. Создайте отдельного бота командой `/newbot` в официальном `https://t.me/BotFather`.
3. Введите выданный токен в поле «Токен бота» в админке. Не отправляйте его в чат и не добавляйте в Git.
4. Откройте ссылку на своего бота из админки, нажмите «Старт».
5. В админке нажмите «Найти чаты», выберите свой чат и нажмите «Подключить».
6. Дождитесь тестового сообщения, отправьте заявку через форму сайта и проверьте список обращений.

До успешного подключения Telegram форма использует прежний переход в WhatsApp.
После подключения сервер сначала сохраняет заявку, затем отправляет уведомление.
Если Telegram временно недоступен, заявка остаётся в админке с кнопкой повторной отправки.
Кнопка заявки в каталоге ведёт к форме с выбранной моделью и мощностью.

Данные и токен хранятся вне корня сайта: по умолчанию `../.vershina8848-leads/`.
PHP должен иметь право создать эту папку. Можно задать другой приватный каталог переменной
окружения `LEADS_PRIVATE_DIR`; размещать его внутри публичного каталога нельзя.
Папка не входит в Git и не перезаписывается публикацией сайта. Включите её в резервное копирование хостинга.

Требуется PHP 8.1+ с HTTPS-доступом к `api.telegram.org` через cURL или URL streams.
Пароль входа берётся из существующего `catalog/admin-config.php`.
Для локальной проверки: `php -S 127.0.0.1:8849 router.php` из папки сайта.
